Docs executable path

Research preview. Not v1.0. Not in General. Helpers on this page are not exported. Call them as BioDynaX.foo. They do not grow the public freeze list.

The executable docs path joins hybrid residual, identifiability product, graph-local library, denominator domain, and parameter schema pack. tutorial, howto, and sciml must not restate closed H–L holes as current facts. Smoke (1 IC / 8 points) is not the seed-103 / 9-IC protocol. This page does not restate the A–G workspaces.

This page does not change RECOVERY_THRESHOLDS, the unique-claim protocol (seed 103 / 9 ICs), or validate_network. Combined F1 stays a skeleton floor (0.50). Hill-from-NN stays closed.

What was still open

H–L each have a locked landing sentence and a helper module. The tutorial still composed hybrid_data_residual without naming those five pages. howto / sciml / architecture listed them one by one without an executable join that can fail when a leftover phrase returns (a missing custom kinetic name, ImplicitCandidate-only counts, local_basis target as a node id).

This page is that join. It does not replace Discovery streaming, Training reuse, SciML solve surface, Recovery suite skip, Experiment fingerprint and checkpoint, Failure modes, or Hybrid compose path.

Executable join

docs_executable_join_row reads the five H–L contract strings. They must stay distinct. leftover_contradiction_hits walks tutorial / howto / sciml / architecture.

using BioDynaX

BioDynaX.docs_executable_contract()

live_hl_kinetic_join_row packs kinetic :k_custom, walks a safe denominator split, and checks the Hill graph-local library. That is 1-IC fixture work, not the seed-103 / 9-IC protocol.

hl_surface_callables_row evaluates the five H–L contract functions. docs_executable_not_faster_protocol_row keeps the seed-103 / 9-IC table. combined_f1_not_docs_kpi_row keeps combined F1 out of the KPI failure symbols.

Leftovers and A–G

no_restated_ag_pages_row fails if this page says it restates an A–G markdown file. make.jl still lists those A–G pages.

Closed leftover phrases (a missing custom kinetic name, a painted UDE F1 of 0.99) must not appear on the four landing files.

What this page does not do

It does not loosen RECOVERY_THRESHOLDS. It does not put a single-hole gate into validate_network. It does not open Hill-from-NN. Combined support F1 stays a skeleton floor (0.50). It does not restate the A–G workspaces.

user_doc_inventory walks every path in unique_claim_user_doc_paths. Leftover hits stay 0. format_docs_executable_report prints the H–L index, leftover catalog, and inventory. hl_own_page_sentences_row requires each H–L page to carry its four locked sentences. ag_pages_still_listed_row keeps the A–G pages in make.jl. readme_leftover_row, index_page_leftover_row, and changelog_does_not_paint_f1_row keep closed leftover phrases off README / index / CHANGELOG. live_hl_ident_join_row reuses the identifiability product extras / KPI honesty rows. Combined F1 is not a KPI failure symbol.
