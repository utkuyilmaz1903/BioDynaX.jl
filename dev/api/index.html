API

Names on the stability freeze plus the golden-path verbs a stranger types in the tutorial. Experimental entry points are not exported; see Experimental.

Network and compile

BioDynaX.BiologicalNetwork — Type
BiologicalNetwork

Species graph (NodeSpec), directed interactions (EdgeSpec), and stoichiometric reactions (ReactionSpec). Unknown edges and reactions compile to neural destruction terms; known families become mechanistic IR.

source
BioDynaX.NodeSpec — Type
NodeSpec

Species node: name, kind (STATE/INPUT/LATENT), bounds, and observation flag.

source
BioDynaX.EdgeSpec — Type
EdgeSpec

Directed interaction. Unknown edges (known=false or UNKNOWN_NN) compile to a neural destruction head; known family values become mechanistic IR.

source
BioDynaX.ReactionSpec — Type
ReactionSpec

Stoichiometric reaction. stoichiometry maps state-node ids to signed coefficients; regulators affect the rate but are not necessarily consumed.

source
BioDynaX.EdgeKind — Type
EdgeKind

Directed-edge semantics used when an EdgeSpec is compiled. ACTIVATION and INHIBITION become mechanistic IR when known=true; UNKNOWN_NN always compiles to a neural destruction head.

source
BioDynaX.ACTIVATION — Constant

Source increases the target production or rate.

source
BioDynaX.INHIBITION — Constant

Source decreases the target production or rate.

source
BioDynaX.UNKNOWN_NN — Constant

Unknown interaction; compiles to NeuralDestructionTerm.

source
BioDynaX.NodeKind — Type
NodeKind

Species role in a BiologicalNetwork. Only STATE and LATENT nodes enter the compiled ODE; INPUT nodes are exogenous drives.

source
BioDynaX.STATE — Constant

Dynamic species integrated by the compiled UDE.

source
BioDynaX.INPUT — Constant

Exogenous drive; not a dynamic state.

source
BioDynaX.LATENT — Constant

Unobserved dynamic species (still in the ODE).

source
BioDynaX.KineticFamily — Type
KineticFamily

Known kinetic template on an edge or reaction. Unknown mechanisms ignore the family and compile to a neural destruction head.

source
BioDynaX.MASS_ACTION — Constant

Mass-action production or first-order regulation.

source
BioDynaX.SATURATION — Constant

Michaelis–Menten saturation (single regulator).

source
BioDynaX.HILL — Constant

Hill-type destruction.

source
BioDynaX.COMPETITIVE — Constant

Competitive-inhibition destruction (two regulators).

source
BioDynaX.CUSTOM_KINETIC — Constant

User evaluator or named kinetic preset.

compile_mechanism(network) -> CompiledMechanism

Lower reactions and edges to production–destruction IR (duᵢ = Pᵢ − Dᵢ·uᵢ). Unknown mechanisms become NeuralDestructionTerm.

source
BioDynaX.UDEModel — Type
UDEModel

Positive-by-construction production/destruction UDE. The invariant form duᵢ = Pᵢ(u,p,t) - Dᵢ(u,p,t)uᵢ, with Pᵢ,Dᵢ ≥ 0, points inward at every zero-state boundary and therefore preserves the biological positive orthant.

source
BioDynaX.ude_system — Function
ude_system(x, p, t, model::UDEModel) -> dx

Evaluate the compiled production–destruction RHS. SVector states with n ≤ STATIC_STATE_THRESHOLD use the StaticArrays kernel.

source
BioDynaX.ude_rhs! — Function
ude_rhs!(du, x, p, t, model, cache)

In-place compiled production–destruction RHS using a preallocated cache.

source
BioDynaX.NeuralDestructionTerm — Type
NeuralDestructionTerm

Unknown destruction rate compiled to a positivity-preserving neural head. regulators are the inputs; regulator is the first (backward compatible).

TrainingConfig

Adam then optional BFGS settings for train_ude / train_experiments. frozen_phys names physical parameters whose raw values are held fixed (gradient zeroed; restored after BFGS). Use this to pin a known production rate; it does not remove k_prod↔D(z) Jacobian collinearity.

BioDynaX.StructuralPositivity — Type
StructuralPositivity

source
BioDynaX.AugmentedLagrangianConfig — Type
AugmentedLagrangianConfig

Smooth inequality-constraint policy. ρ is updated automatically from primal progress; users do not select a fixed penalty multiplier.

BioDynaX.AbstractConstraintStrategy — Type
AbstractConstraintStrategy

Training constraint policy. StructuralPositivity relies on the compiled P,D ≥ 0 form; AugmentedLagrangianConfig adds a smooth penalty.

source

BioDynaX.ProductionAD — Type
ProductionAD

Production forward pass using the in-place compiled RHS (ude_rhs!) with a preallocated cache when sensealg = nothing. Adjoint training continues to use the out-of-place RHS because Zygote cannot differentiate through the mutating cache path today.

discover_equations(p_trained, model::UDEModel; kwargs...)
discover_equations(p_trained, model, set::ExperimentSet; kwargs...)
discover_equations(X, times, network; kwargs...)

Recover graph-local equations from a trained UDE, several experiments, or raw trajectories. Failures set DiscoveryResult.retcode; pass strict=true to throw. The raw-data method accepts targets to recover a subset of state rows.

source
discover_equations(X, times, network; config, ...)

UDE-free discovery from observed trajectories. Derivatives are estimated by central finite differences unless derivatives is supplied. Pass targets to recover a subset of state rows (used for rate-only unknown-edge discovery).

source
discover_equations(p_trained, nn, st; ...)

Discover graph-local rational dynamics with SINDy-PI's implicit identity D(z)ẋ - N(z)=0. Unknown numerator and denominator coefficients are learned jointly; no fixed-denominator rational atoms or Taylor approximations are used.

source
BioDynaX.discover_unknown_rate — Function
discover_unknown_rate(R, times, D; network, config, ...)

Discover a scalar destruction rate D(r) with graph-local implicit SINDy-PI. R is n_regulators × n and D is 1 × n.

source

Contract

BioDynaX.RECOVERY_THRESHOLDS — Constant
RECOVERY_THRESHOLDS

Locked scientific-recovery contract. Loosening a threshold is a breaking change. UDE combined F1 is not the analytical Hill gate; that gate is support_f1_clean on exact/noisy analytical D. A same-library F1 attempt (benchmark/ude_f1_attempt.jl) left extras 1 and r. The UDE claim is recall + data residual until a new major gate.

source
