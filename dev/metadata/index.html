Typed kinetic metadata

Edges and reactions accept typed metadata structs instead of untyped dictionaries. Dict metadata remains supported for backward compatibility during the 0.x migration.

Example

ReactionSpec(
    name = :Mdm2_linear_decay,
    stoichiometry = Dict(3 => -1.0),
    regulators = Int[],
    metadata = LinearDecayMetadata(rate_param = :γ_mdm2),
)

ReactionSpec(
    name = :input_drives_p53,
    stoichiometry = Dict(2 => 1.0),
    metadata = InputDriveMetadata(
        rate_param = :α_p53,
        input_param = :signal,
        input_node = 1,
    ),
)

Available metadata types

BioDynaX.KineticMetadata — Type
KineticMetadata

Typed compile-time metadata for edges and reactions. Replaces ad-hoc Dict{Symbol,Any} fields with SciML-style explicit structs while retaining backward-compatible dict coercion during the 0.x migration.

source
BioDynaX.EmptyMetadata — Type

Empty metadata placeholder.

source
BioDynaX.InputDriveMetadata — Type

Input-driven production (e.g. damage signal drives p53).

source
BioDynaX.MassActionMetadata — Type

Mass-action production or regulation.

source
BioDynaX.HillMetadata — Type

Hill-type destruction kinetics.

source
BioDynaX.CompetitiveMetadata — Type

Competitive inhibition destruction kinetics.

source
BioDynaX.LinearDecayMetadata — Type

First-order linear decay.

source
BioDynaX.SaturationMetadata — Type

Michaelis–Menten saturation kinetics (single regulator).

source
BioDynaX.CustomKineticMetadata — Type
CustomKineticMetadata

User-defined or preset destruction/production kinetics. When evaluator is set, it must be a pure function (x, p, regulators) -> non-negative rate coefficient.

source
