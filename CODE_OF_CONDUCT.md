# Contributor Covenant Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
the same community standard used by SciML / ColPrac.

## Our Pledge

We pledge to make participation in this project a harassment-free experience
for everyone.

## Enforcement

Report unacceptable behavior to the maintainer listed in `Project.toml`
(`authors`). This is a research-preview scientific package; disagreements
about recovery thresholds, exports, or experimental APIs belong in issues
and must not loosen `RECOVERY_THRESHOLDS` or grow the public export list.
